# 🚀 Projets Principaux

### 🧭 Bideyeti

**Plateforme Intelligente d'Orientation Universitaire**

Une plateforme intelligente qui aide les bacheliers tunisiens à explorer les universités, les spécialités, les scores d'admission et les opportunités professionnelles en fonction de leurs profils et centres d'intérêt.

**Stack :** React • TypeScript • Node.js • Prisma • Gemini API

> Développé dans le cadre d'un travail d'équipe, avec une contribution aux APIs backend, aux jeux de données universitaires structurés, aux recommandations basées sur l'IA et à la conception du système.

---

### 🏃 TuniFit

**Plateforme Full-Stack de Suivi de la Santé**

Une application web permettant de suivre les calories, le sommeil, l'hydratation et l'alimentation tunisienne, avec un tableau de bord d'administration pour l'analyse des données et la gestion de la base de données.

**Stack :** React • Node.js • Express.js • MongoDB

---

### 🧪 Framework d'Automatisation des Tests

**Tests Logiciels End-to-End & Automatisation**

Modernisation et stabilisation d'un framework de tests automatisés utilisant Playwright, Cucumber.js et Gherkin.

- ♻️ Page Objects réutilisables
- 🧩 Step definitions génériques
- 🏗️ Composants d'automatisation partagés
- ✅ 500+ cas de test validés
- 📊 Génération automatisée de rapports de tests Excel
